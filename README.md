# Interview Flashcards

면접 질문과 준비한 답변을 저장하고, 카드 방식으로 반복 연습할 수 있는 프론트엔드 MVP입니다. 데이터는 브라우저 `localStorage`에 저장되며 별도 백엔드는 필요하지 않습니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본값 `http://localhost:5173`)를 브라우저에서 여세요. 배포용 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`로 실행합니다.

## 주요 기능

- 카테고리별 메인 질문과 여러 꼬리질문 등록, 수정, 삭제 및 목록 조회
- 질문 목록의 위·아래 이동 버튼으로 연습 카드 순서 변경
- 확인 절차를 거쳐 모든 질문과 꼬리질문 전체 삭제
- 사용자 폴더 생성·이름 변경·삭제 및 폴더별 질문 관리/연습
- 현재 선택한 폴더로 JSON 가져오기 및 폴더 단위 내보내기
- 메인 질문 뒤에 꼬리질문을 순서대로 이어가는 카드 연습
- 순차/랜덤 모드, 답변 보기/숨기기, 이전/다음 이동
- 연습 화면에서 키보드 좌우 방향키로 이전/다음 질문 이동
- 연습 카드 상단의 면접관 패널 일러스트와 이미지 로딩 실패 폴백
- 사용자가 직접 켜고 끌 수 있는 웹캠 미리보기와 권한 오류 폴백
- 마이크로 답변을 녹음하고 즉시 다시 듣는 음성 녹음 기능
- 질문이 바뀔 때 초기화되는 질문별 답변 시간 타이머
- 연습 화면에서 현재 메인 질문과 꼬리질문을 바로 수정하는 빠른 편집
- 현재 진행 위치 표시
- `localStorage` 자동 저장 및 최초 실행용 샘플 질문 3개
- 여러 질문 JSON 가져오기 및 전체 데이터 JSON 내보내기
- PC 중심의 반응형 UI

## JSON 가져오기 형식

아래와 같이 메인 질문 객체의 배열을 사용합니다. `followUps`에는 0개 이상의 꼬리질문을 넣을 수 있습니다. 내보낸 JSON 파일도 그대로 다시 가져올 수 있으며, 가져오기는 기존 데이터에 질문을 추가합니다. `category`와 `followUps`는 생략할 수 있고 각각 `미분류`, 빈 배열로 처리됩니다. 준비 중인 꼬리질문의 `answer`는 빈 문자열이어도 가져올 수 있습니다.

```json
[
  {
    "category": "공통",
    "question": "본인의 강점은 무엇인가요?",
    "answer": "직무 경험과 구체적인 사례를 중심으로 답변합니다.",
    "followUps": [
      {
        "question": "그 강점을 발휘한 구체적인 사례가 있나요?",
        "answer": "상황, 행동, 결과 순서로 설명합니다."
      },
      {
        "question": "그 강점이 오히려 단점이 된 적은 없나요?",
        "answer": "한계를 인정하고 보완 방법을 함께 설명합니다."
      }
    ]
  }
]
```

## 프로젝트 구조

```text
src/
├─ components/   # 질문 폼, JSON 데이터 도구
├─ context/      # 질문 상태와 CRUD 동작
├─ data/         # 최초 샘플 데이터
├─ pages/        # 연습 화면, 질문 관리 화면
├─ types/        # 공통 TypeScript 타입
└─ utils/        # localStorage, JSON 검증, 셔플
```
